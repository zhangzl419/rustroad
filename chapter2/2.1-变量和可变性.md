# 2.1 变量和可变性

Rust 中的变量，默认是不可变的。也就是说，变量一旦绑定到一个值，后面就不能直接修改它。

这种设计的好处是，程序更容易理解，很多错误也能更早被编译器发现。如果一个值本来就不需要改变，就没有必要允许它随意被改动。

先看最基本的写法：

```rust
fn main() {
    let x = 5;
    println!("x = {}", x);
}
```

这里的 `x` 是不可变变量。如果你尝试修改它，编译器会报错：

```rust
fn main() {
    let x = 5;
    x = 6; // 错误：不能直接修改不可变变量
}
```

如果确实需要修改，就在声明时加上 `mut`：

```rust
fn main() {
    let mut x = 5;
    println!("x = {}", x);

    x = 6;
    println!("x = {}", x);
}
```

`mut` 表示这个变量是可变的。实际开发中，能少用就少用，因为不可变代码通常更清楚，也更安全。

Rust 还支持“变量遮蔽”。也就是用同一个名字重新声明一个变量：

```rust
fn main() {
    let x = 5;
    let x = x + 1;
    let x = x * 2;

    println!("x = {}", x);
}
```

遮蔽和修改不是一回事。修改是同一个变量变了，遮蔽是新的变量把旧变量盖住了。这在重新整理数据、改变数据类型时很有用。

2.6 表达式和语句

2.6 表达式和语句

这一节是 Rust 初学者最容易“看懂代码、却没真正理解”的地方。很多语言里，表达式和语句的区别并不会被反复强调，但在 Rust 中，这个区别非常重要，因为它直接影响变量赋值、函数返回值和代码块写法。

什么是语句

语句通常表示“执行一个动作”，它本身不一定产生有用的值。

例如：

fn main() {
    let x = 5;
}

这里的 let x = 5; 就是一条语句。它完成的是“定义变量”这件事。

什么是表达式

表达式的特点是：它会计算出一个值。

例如：

let sum = 1 + 2;

其中 1 + 2 就是表达式，它的值是 3。

再比如函数调用、比较运算、代码块，在 Rust 中往往也都是表达式。

代码块也是表达式

这是 Rust 中一个非常关键的特点。代码块 { ... } 不只是“把几行代码包起来”，它本身也可以产生值。

fn main() {
    let y = {
        let x = 3;
        x + 1
    };

    println!("y = {}", y);
}

上面代码中，花括号里的最后一行是 x + 1，它没有分号，因此整个代码块的值就是 4，最后赋给了 y。

分号为什么重要

在 Rust 中，分号经常决定一段代码是“表达式”还是“仅仅作为语句结束”。

看下面这段代码：

fn main() {
    let y = {
        let x = 3;
        x + 1
    };

    println!("{}", y);
}

如果把最后一行改成：

x + 1;

那么整个代码块的值就不再是 4，而会变成 ()，也就是 Rust 中的单元类型。你可以把它理解为“没有有意义的返回值”。

所以，Rust 中最后一行有没有分号，往往不是格式问题，而是语义问题。

if 也可以是表达式

这也是 Rust 风格里非常常见的写法：

fn main() {
    let condition = true;

    let number = if condition { 5 } else { 6 };
    println!("{}", number);
}

这里 if ... else ... 不是单纯的流程控制语句，它本身也是表达式，因此它的结果可以直接赋给变量。

不过要注意，if 两个分支返回的值类型必须一致，否则编译器无法确定整个表达式的类型。

这和函数返回值有什么关系

你后面会看到，Rust 函数也经常把“最后一个表达式的值”作为返回值：

fn add(a: i32, b: i32) -> i32 {
    a + b
}

这里没有写 return，但最后一行 a + b 是表达式，因此函数会把它的值返回出去。

所以可以说，理解表达式和语句，不只是为了看懂一小段代码，而是为了真正理解 Rust 的整体写法。

初学者常见误区

1. 把分号当成“可有可无”

在很多语言里，分号更多是语法结尾标记；但在 Rust 中，分号经常会改变值是否被返回。

2. 以为花括号只是分组

Rust 的代码块往往是有值的，这一点和不少传统语言差别很大。

3. 写函数时总想强行加 return

return 当然可以用，但 Rust 很多时候更鼓励直接使用最后一个表达式作为返回值。这样代码更简洁，也更符合 Rust 风格。

本节小结

语句更偏向“做一件事”，表达式更偏向“算出一个值”。Rust 大量依赖表达式来组织代码，因此你必须尽早建立这个概念。尤其要记住：最后一行有没有分号，常常决定一段代码有没有返回值。

测试题

  1. 表达式和语句最核心的区别是什么？
  2. 为什么代码块 { ... } 可以赋值给变量？
  3. Rust 中最后一个表达式后面加不加分号，会带来什么变化？

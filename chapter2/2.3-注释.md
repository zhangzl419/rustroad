# 2.3 注释

注释是写给人看的，不是写给机器看的。编译器会忽略注释，但读代码的人会从注释中快速理解程序意图。

Rust 常见的注释有三种。

单行注释最常用：

```rust
fn main() {
    // 这是单行注释
    let x = 5;
}
```

多行注释适合说明较长的内容：

```rust
/* 这是多行注释
   可以写很多行 */
fn main() {}
```

文档注释用于生成说明文档，常写在函数、结构体、模块上方：

```rust
/// 计算两个数的和
fn add(a: i32, b: i32) -> i32 {
    a + b
}
```

写注释时，要注意不要只是重复代码，而要解释代码为什么这么写，或者这里到底在做什么。

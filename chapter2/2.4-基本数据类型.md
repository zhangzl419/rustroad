# 2.4 基本数据类型

Rust 是静态类型语言。也就是说，变量一旦确定了类型，编译器就会严格检查。

Rust 的基本数据类型可以分为两类：标量类型和复合类型。

标量类型包括整数、浮点数、布尔值和字符。

```rust
let a: i32 = 10;
let b: f64 = 3.14;
let c: bool = true;
let d: char = '中';
```

整数有很多种，比如 `i8`、`i32`、`u32` 等。`i` 表示有符号整数，`u` 表示无符号整数。初学时最常见的是 `i32`。

复合类型主要有元组和数组。

```rust
let tup: (i32, f64, char) = (10, 2.5, 'R');
let arr: [i32; 3] = [1, 2, 3];
```

元组可以把不同类型的数据放在一起，数组则要求每个元素类型相同，而且长度固定。

理解数据类型的关键，是先想清楚“这个值是什么”，再决定它应该用什么类型表示。

# 2.6 表达式和语句

Rust 中有一个很重要的区别：表达式会产生值，语句通常只负责执行动作。

```rust
fn main() {
    let x = 5;
}
```

上面的 `let x = 5;` 是语句，因为它完成的是“定义变量”这件事。

而下面这段代码里，代码块 `{ ... }` 本身是表达式：

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };

    println!("y = {}", y);
}
```

这里最后一行 `x + 1` 没有分号，所以整个代码块的值就是 `4`。

如果加上分号，它就变成语句，代码块的结果也会变成 `()`，也就是“空值”。

理解表达式和语句，有助于你读懂 Rust 的代码风格。很多 Rust 代码看起来简洁，就是因为它充分利用了表达式返回值的特性。

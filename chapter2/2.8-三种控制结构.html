2.8 三种控制结构

2.8 三种控制结构

如果程序只是从第一行机械地执行到最后一行，那它能做的事情其实非常有限。真正有用的程序，必须能够根据条件做选择，也必须能够重复执行某些操作。

从整体上看，程序最常见的控制结构可以概括为三种：

  • 顺序结构
  • 分支结构
  • 循环结构

这三种结构并不只存在于 Rust 中，但 Rust 对它们的写法和约束有自己的风格。

顺序结构

顺序结构最简单，也最基础。它的意思是：代码默认按照从上到下的顺序依次执行。

fn main() {
    println!("第一步");
    println!("第二步");
    println!("第三步");
}

如果没有遇到分支、循环、函数调用等额外控制逻辑，程序就会沿着这条顺序一直往下走。

顺序结构看起来很普通，但它是其他所有控制结构的基础。分支和循环，本质上都是对“默认顺序执行”的扩展。

分支结构

分支结构的作用是：根据条件不同，执行不同路径的代码。

Rust 中最常见的分支写法是 if、else if 和 else：

fn main() {
    let score = 85;

    if score >= 90 {
        println!("优秀");
    } else if score >= 60 {
        println!("及格");
    } else {
        println!("不及格");
    }
}

这里程序不会把三个分支都执行一遍，而是只会选择其中一个满足条件的分支。

if 条件必须是布尔值

Rust 在条件判断上比较严格。if 后面的条件必须明确是 bool 类型，不能像某些语言那样把整数直接当成真假值使用。

也就是说，Rust 更倾向于要求你写清楚：

if number != 0 {
    // ...
}

而不是模糊地依赖“非零就算真”这种隐式规则。

if 也是表达式

这一点和上一节的内容又联系起来了。Rust 中 if 不只是流程控制语句，它还可以直接产生值：

fn main() {
    let condition = true;
    let number = if condition { 1 } else { 0 };
    println!("{}", number);
}

这种写法在 Rust 里非常常见，但要记住一个要求：if 和 else 两边产生的值类型必须一致。

循环结构

循环结构用于重复执行一段代码。Rust 里最常见的循环有三种：

  • loop
  • while
  • for

loop：一直循环，直到主动退出

loop 是最直接的一种循环，它会不停执行，直到遇到 break：

fn main() {
    let mut count = 0;

    loop {
        count += 1;

        if count == 3 {
            break;
        }
    }

    println!("count = {}", count);
}

如果没有 break，这个循环就不会自己结束。所以使用 loop 时，一定要清楚退出条件写在哪里。

while：条件成立就继续

while 更适合“只要条件满足，就继续重复”的场景：

fn main() {
    let mut count = 0;

    while count < 3 {
        println!("count = {}", count);
        count += 1;
    }
}

这种写法比 loop + if + break 更直接，因为退出条件就写在循环头部。

for：遍历范围或集合

for 常用于遍历一组数据，或者遍历某个固定范围：

fn main() {
    for n in 1..4 {
        println!("{}", n);
    }
}

这里的 1..4 表示从 1 到 3，不包含 4。

如果想包含右边界，可以写成 1..=4：

fn main() {
    for n in 1..=4 {
        println!("{}", n);
    }
}

在 Rust 中，for 往往比手动控制下标更安全、更简洁，因此当你只是想遍历数据时，通常优先考虑 for。

break 和 continue

在循环中，两个常见的控制关键字是：

  • break：立刻结束整个循环
  • continue：跳过本次循环剩余部分，进入下一轮

示例：

fn main() {
    for n in 1..=5 {
        if n == 3 {
            continue;
        }

        if n == 5 {
            break;
        }

        println!("{}", n);
    }
}

这段代码里：

  • 遇到 3 时，不打印，直接进入下一轮
  • 遇到 5 时，整个循环结束

三种循环如何选择

初学时可以先这样理解：

  • 不确定执行多少次，但确定会主动退出时，用 loop
  • 根据某个条件反复执行时，用 while
  • 遍历范围、数组或集合时，用 for

实际开发中，for 往往是最常用、也最推荐优先考虑的一种循环写法。

本节小结

控制结构决定了程序“怎么走”。顺序结构是默认执行方式，分支结构让程序根据条件做选择，循环结构让程序重复完成任务。真正写代码时，不只是要会写 if 和 for，还要能根据场景判断哪种结构最合适。

  2. 为什么 Rust 要求 if 条件必须是布尔值？

# 2.5 运算符

变量和数据类型解决的是“数据怎么表示”的问题，运算符解决的是“数据怎么处理”的问题。加法、比较大小、逻辑判断、重新赋值，这些都要依赖运算符。

Rust 中常见的运算符可以先分为四类：

- 算术运算符
- 比较运算符
- 逻辑运算符
- 赋值运算符

## 算术运算符

算术运算符用于进行数学计算，最常见的有：

- `+` 加法
- `-` 减法
- `*` 乘法
- `/` 除法
- `%` 取余

示例：

```rust
fn main() {
    let a = 10 + 3;
    let b = 10 - 3;
    let c = 10 * 3;
    let d = 10 / 3;
    let e = 10 % 3;

    println!("a = {}", a);
    println!("b = {}", b);
    println!("c = {}", c);
    println!("d = {}", d);
    println!("e = {}", e);
}
```

这里需要特别注意 `10 / 3` 的结果。因为两个操作数都是整数，所以结果也是整数，小数部分会被舍去，结果是 `3`，而不是 `3.3333`。

如果你想得到带小数的结果，就要使用浮点数：

```rust
fn main() {
    let result = 10.0 / 3.0;
    println!("{}", result);
}
```

## 比较运算符

比较运算符用于判断两个值之间的关系，结果是布尔值：

- `==` 等于
- `!=` 不等于
- `>` 大于
- `<` 小于
- `>=` 大于等于
- `<=` 小于等于

```rust
fn main() {
    let a = 5 > 3;
    let b = 5 == 3;
    let c = 5 != 3;

    println!("a = {}", a);
    println!("b = {}", b);
    println!("c = {}", c);
}
```

比较运算通常会出现在 `if` 条件、循环判断以及各种业务规则校验中。

## 逻辑运算符

逻辑运算符用于组合布尔值：

- `&&` 逻辑与
- `||` 逻辑或
- `!` 逻辑非

```rust
fn main() {
    let a = true && false;
    let b = true || false;
    let c = !true;

    println!("a = {}", a);
    println!("b = {}", b);
    println!("c = {}", c);
}
```

逻辑运算常用于多个条件组合判断。例如，只有“用户名非空并且密码长度足够”时，才允许提交。

## 赋值运算符

最基础的赋值运算符是 `=`，表示把右侧的值赋给左侧变量：

```rust
fn main() {
    let mut x = 10;
    x = 20;
    println!("{}", x);
}
```

Rust 也支持一些组合赋值写法，例如：

- `+=`
- `-=`
- `*=`
- `/=`

```rust
fn main() {
    let mut score = 10;
    score += 5;
    score *= 2;
    println!("{}", score);
}
```

这些写法本质上只是更紧凑的简写形式。

## Rust 中没有 `++` 和 `--`

如果你学过 C、C++、Java 或 JavaScript，可能会下意识寻找 `++` 和 `--`。Rust 没有这两个运算符。

也就是说，下面这样的写法在 Rust 中是错误的：

```rust
// value++;
// value--;
```

正确做法是显式写成：

```rust
value += 1;
value -= 1;
```

Rust 这样设计，是为了避免某些写法虽然简短，却容易造成阅读歧义。

## 一个常见问题：类型必须匹配

Rust 对运算非常严格。不同类型的值通常不能直接混合运算。

例如，整数和浮点数不能随手相加，编译器通常会要求你先把类型处理清楚。这样虽然少了一点“随意性”，但能显著减少隐式转换带来的错误。

## 本节小结

运算符只是符号，真正重要的是你是否清楚数据之间要进行什么关系和计算。Rust 在运算这件事上追求明确：类型要清楚、结果要可预期、语义不要模糊。你越早习惯这一点，后面的代码就越不容易出错。

# 2.5 运算符

运算符就是用来对数据做操作的符号。Rust 中常见的运算符包括算术运算符、比较运算符、逻辑运算符和赋值运算符。

算术运算符用于加减乘除：

```rust
let a = 10 + 3;
let b = 10 - 3;
let c = 10 * 3;
let d = 10 / 3;
```

比较运算符用于判断大小或相等：

```rust
let x = 5 > 3;
let y = 5 == 3;
```

逻辑运算符常用于条件判断：

```rust
let a = true && false;
let b = true || false;
let c = !true;
```

Rust 中没有 `++` 和 `--` 这样的自增、自减运算符，所以不要把 C 或 C++ 的习惯直接带过来。

很多时候，运算符只是表达意思的一种简写。真正重要的，是先把计算逻辑想清楚，再选择合适的写法。

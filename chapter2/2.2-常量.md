# 2.2 常量

常量是程序中永远不会改变的值。和变量不同，常量从定义开始就不能再修改。

Rust 中定义常量使用 `const`，并且必须写明类型：

```rust
const MAX_POINTS: u32 = 100_000;

fn main() {
    println!("MAX_POINTS = {}", MAX_POINTS);
}
```

常量适合保存那些在程序运行期间始终固定的值，比如最大数量、固定参数、数学常数等。

常量和不可变变量很像，但它们不是一回事：

- 常量必须在编译时就能确定。
- 常量不能使用 `mut`。
- 常量通常用于全局共享的固定值。

如果一个值只是“暂时不变”，可以用不可变变量；如果一个值“从头到尾都不应该变”，就用常量。

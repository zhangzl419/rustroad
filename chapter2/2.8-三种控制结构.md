# 2.8 三种控制结构

程序并不是一直直线往下执行的。很多时候，我们需要根据条件选择不同的路径，或者重复执行某些代码。

从整体上看，程序常见的控制结构有三种：顺序结构、分支结构和循环结构。

顺序结构最简单，代码默认从上往下执行：

```rust
fn main() {
    println!("第一步");
    println!("第二步");
}
```

分支结构用来做选择，Rust 中最常见的是 `if` 和 `else`：

```rust
fn main() {
    let number = 6;

    if number % 2 == 0 {
        println!("偶数");
    } else {
        println!("奇数");
    }
}
```

循环结构用来重复执行代码。Rust 提供了 `loop`、`while` 和 `for`：

```rust
fn main() {
    let mut count = 0;

    while count < 3 {
        println!("count = {}", count);
        count += 1;
    }
}
```

其中，`for` 常用于遍历集合或固定范围，`while` 更适合“只要条件成立就继续”的场景，`loop` 则会一直执行，直到你主动退出。

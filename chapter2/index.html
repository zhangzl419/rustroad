第2章 Rust基础知识

第2章 Rust基础知识

学习一门语言时，最容易被忽视的，往往正是“最基础”的部分。变量、常量、类型、函数、控制结构，这些概念看起来并不复杂，但后面所有稍微深入一点的内容，几乎都建立在它们之上。

Rust 的基础知识和很多传统语言有相似之处，但又有一些非常鲜明的特点。比如，变量默认不可变、代码块本身可以作为表达式、函数最后一行的值可以直接作为返回值。这些设计如果只是草草看过，后面学习所有权、借用、结构体、枚举和模式匹配时，就会不断遇到理解障碍。

因此，这一章的目标不是“把语法点扫一遍”，而是把最常用、最核心的编程概念用 Rust 的方式真正讲清楚。学完这一章后，你至少应该建立下面几个基本认识：

  • Rust 中变量默认不可变，可变需要显式声明。
  • 常量和普通变量相似，但它们的用途、约束和适用场景并不一样。
  • Rust 是静态类型语言，很多错误会在编译阶段就被发现。
  • 表达式和语句的区别，在 Rust 中比很多语言更重要。
  • 函数和控制结构不只是语法形式，它们决定了代码如何组织和运行。

本章包括以下内容：

  1. 变量和可变性
    理解 let、mut、变量遮蔽，以及 Rust 为什么默认鼓励不可变。
  2. 常量
    区分“暂时不变的变量”和“从定义起就不应该改变的值”。
  3. 注释
    学会写有价值的注释，而不是简单重复代码。
  4. 基本数据类型
    认识 Rust 中最常见的标量类型和复合类型。
  5. 运算符
    理解算术、比较、逻辑和赋值运算的基本规则。
  6. 表达式和语句
    这是 Rust 初学者必须尽快建立起来的一个关键概念。
  7. 函数定义
    学会定义函数、声明参数和返回值，并理解 Rust 的返回风格。
  8. 三种控制结构
    理解顺序、分支和循环，让程序具备“根据情况做不同事情”的能力。

建议你在学习这一章时，不要只看代码“长什么样”，更要问自己两个问题：

  • 这段代码为什么可以这样写？
  • 如果稍微改动一下，编译器会接受还是会报错？

如果你能带着这两个问题去读每一节内容，这一章就不只是“入门语法”，而会成为后面继续深入 Rust 的牢固地基。

每一节后面都配有 2 到 3 道测试题。它们不是为了刁难你，而是帮助你检查自己是否真的理解了概念，而不是只记住了几个关键词。

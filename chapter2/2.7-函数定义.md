# 2.7 函数定义

函数是把一段相关逻辑封装起来的方式。写好函数后，可以反复调用，既能减少重复，也能让程序更清楚。

Rust 中定义函数用 `fn` 关键字。

```rust
fn greet() {
    println!("Hello, Rust!");
}

fn main() {
    greet();
}
```

如果函数需要参数，就在括号里写出来，并标明类型：

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b
}

fn main() {
    let sum = add(3, 4);
    println!("sum = {}", sum);
}
```

Rust 的函数名通常使用小写字母加下划线的风格，比如 `add_number`、`print_result`。这是一种常见的代码规范。

函数最后一个表达式的值，通常就是函数的返回值。如果想提前返回，也可以使用 `return`。

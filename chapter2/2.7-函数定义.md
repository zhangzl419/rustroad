# 2.7 函数定义

函数的作用，是把一段可以独立完成特定任务的逻辑封装起来。程序规模一旦稍微变大，如果没有函数，代码很快就会变得重复、混乱，而且难以维护。

从学习编程的角度看，函数至少解决三个问题：

- 复用逻辑，避免重复写同样的代码
- 给一段代码起名字，让程序结构更清晰
- 通过参数和返回值，让不同部分之间形成明确的输入输出关系

## 函数的基本定义

Rust 使用 `fn` 关键字定义函数：

```rust
fn greet() {
    println!("Hello, Rust!");
}

fn main() {
    greet();
}
```

这里：

- `fn` 表示这是一个函数定义
- `greet` 是函数名
- `()` 表示这个函数没有参数
- 花括号里的内容是函数体

## 函数参数

如果函数需要接收外部输入，就要定义参数：

```rust
fn print_number(x: i32) {
    println!("x = {}", x);
}

fn main() {
    print_number(10);
}
```

这里的 `x: i32` 表示参数 `x` 的类型是 `i32`。

Rust 对函数参数要求非常明确：参数类型必须写出来。编译器不会像某些场景下那样帮你“猜”函数参数的类型。这种明确性是 Rust 设计中非常重要的一部分。

## 带返回值的函数

函数不仅可以接收输入，也可以返回结果：

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b
}

fn main() {
    let sum = add(3, 4);
    println!("sum = {}", sum);
}
```

这里有两个关键点：

- `-> i32` 表示函数返回 `i32` 类型的值
- 函数体最后一行 `a + b` 没有分号，因此它的值会被直接返回

这正好和上一节“表达式和语句”的内容连起来了。函数返回值很多时候就是“最后一个表达式的值”。

## `return` 什么时候用

Rust 支持 `return`，尤其适合提前结束函数：

```rust
fn abs(n: i32) -> i32 {
    if n >= 0 {
        return n;
    }

    -n
}
```

在这个例子里，如果 `n` 大于等于 0，就立即返回 `n`；否则继续执行后面的 `-n`。

所以可以这样理解：

- 正常情况下，Rust 常用最后一个表达式作为返回值
- 需要提前退出时，使用 `return` 会更直接

## 参数和实参

虽然很多时候大家不会严格区分这两个词，但你最好知道它们的含义：

- 函数定义中的 `a: i32`、`b: i32` 叫参数
- 调用函数时传入的 `3`、`4` 叫实参

理解这个术语，后面阅读文档或错误信息时会更顺畅。

## 函数命名风格

Rust 里函数名通常使用小写字母加下划线的风格，也就是 snake_case：

```rust
fn print_result() {}
fn calculate_total() {}
```

这种命名方式已经成为 Rust 社区的常见约定。遵循这种风格，代码会更自然，也更容易和生态里的其他项目保持一致。

## 一个常见错误：多写了分号

初学者写返回值函数时，最常见的问题之一就是这样：

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b;
}
```

这里最后一行多了分号，结果这行就不再返回 `i32`，而变成了一条语句，函数体最后得到的是 `()`。这会和 `-> i32` 发生冲突，从而导致编译错误。

所以，如果你写的是“用最后一个表达式返回值”的风格，就一定要留意最后一行后面不要随手加分号。

## 本节小结

函数是组织程序结构的核心工具。Rust 在函数设计上强调两点：输入输出类型要明确，返回值要和表达式机制保持一致。你只要把“参数类型显式声明”和“最后一个表达式可以返回值”这两点抓牢，函数部分就不会乱。
